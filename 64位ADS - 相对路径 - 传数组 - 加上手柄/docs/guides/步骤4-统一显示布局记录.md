# 步骤 4：统一显示布局和独立状态

实施日期：2026-10-07

## 实施结果

- 新增 `Controls/DsaImageView.xaml(.cs)`：独立 DSA JPEG 入口，默认显示“等待DSA影像”；只在成功解码并显示 JPEG 后标记在线，2 秒无新帧标记过期。
- `MainWindow` 显示区明确标注 DSA影像、监控1、监控2、DSA机械臂模型。
- 默认布局：DSA影像为上方主要画面；监控1/2为右侧辅助画面；DSA机械臂模型恢复到原来下方左侧位置，并保持较大区域；消息区压缩为窄栏。
- 点击 DSA影像、监控1、监控2时只调整 WPF Grid 的行列，不重建 `WindowsFormsHost`、PictureBox 或海康会话。
- 点击模型时扩大下方模型区域并压缩消息区；VTK 控件仍保持原实例。
- 原有 `Window_Deactivated -> StopAllHoldActions()` 和按住动作按钮逻辑未修改。

## 验证

```powershell
dotnet build master/MasterConsole/MasterConsole.csproj -c Debug -p:Platform=x64 --no-restore
dotnet build master/MasterConsole/MasterConsole.csproj -c Release -p:Platform=x64 --no-restore
```

Debug/Release 均通过。离线 `--sim` 启动窗口保持响应；实际 DSA 帧、海康实机画面和多 DPI 视觉验收仍待实机/人工确认。
