# 步骤 2：独立 DSA 机械臂状态接口

日期：2026-10-07  
范围：只增加 RobotViewport 的状态契约和显式离线注入；未绑定真实网络协议，未接入独立 DSA 控制程序。

## 已实施

- 在 `Controls/RobotViewport.xaml.cs` 增加公开 `DsaArmDisplayState` 类型。
- `Sj` 固定为 7 个已经转换到旧模型显示坐标的值，顺序为 `sj1..sj7`；`sj1/sj2/sj6` 单位为米，其余为弧度。
- `Xj` 固定为 2 个值，顺序为 `xj1..xj2`，单位为弧度。
- `V1/V2` 保留旧 `ct.v1/ct.v2` 原值，只按 `ct v1/v2` 显示，不推断单位。
- 增加 `PublishDsaArmState(state)` 和 `PublishTestDsaArmState(state)`。发布时严格检查数组长度和有限值，复制数组并写入本地 `Stopwatch` 单调时间戳；非法输入返回 `false`，不覆盖旧姿态、不刷新时间。
- 使用 `Interlocked.Exchange` 只保留最新待处理快照。UI `DispatcherTimer` 每 50 ms 在 UI 线程取一次，调用 `MoveJoint`、`UpdateMove` 和 VTK Render；没有新快照时不重复渲染。
- 首次无数据仍显示旧零姿态；收到真实接口数据后显示“DSA机械臂状态：在线”。超过 1000 ms 没有新快照时保留最后姿态并显示“过期（保留最后姿态）”。恢复新数据后重新显示在线。
- 增加“发布测试数据”按钮。每次点击先运行离线契约自检，再只改变 9 个动态关节中的一个，循环覆盖 `sj1..sj7/xj1..xj2`；状态明确标为“测试数据”。不会自动把无网络状态标为在线。
- 模型状态完全独立于 `RemoteRobotLink`、`StatusFrame`、`AxisPos`、`AxisFromLeft` 和 `arm_act_pos`。
- 窗口关闭时停止状态定时器、清空待处理快照，并在 UI 线程释放 VTK 控件。

## 旧转换边界

本步骤只接收已转换的显示值，没有导入 DSA 类、没有启动 DSA 构造函数、没有增加网络适配器。未来发送端若只提供原始 `u/d/P6`，转换只能在唯一适配边界执行：

```text
sj1 = u1 + 4.12288*0.001
sj2 = u2 - 96.2203*0.001
sj3 = -(u3 + 18.2306/180.0*3.14159)
sj4 = u4 - 1.47907/180.0*3.14159
sj5 = u5 + 1.34638/180.0*3.14159
sj6 = u6 - 5.50232*0.001 + P6*0.001
sj7 = u7 - 25.2479/180.0*3.14159
xj1 = d1
xj2 = d2 - 2.0/180.0*3.14159
```

如果未来发送端直接提供 `sj/xj`，主端直接发布，不能二次加偏移。

“发布测试数据”入口内置的契约自检覆盖：非法长度、NaN、发布后修改原数组、单调时间过期/恢复；按钮循环覆盖九个动态关节。未执行真实 DSA 状态联调。
