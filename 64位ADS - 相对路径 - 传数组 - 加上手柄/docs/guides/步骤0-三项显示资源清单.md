## 2. 关节、单位和数值来源

URDF 关节定义：

| 关节 | 类型 | 轴向 | 单位/语义 |
|---|---|---|---|
| `sj0` | fixed | `(0,0,0)` | 固定 |
| `sj1` | prismatic | `(0,1,0)` | 米 |
| `sj2` | prismatic | `(1,0,0)` | 米 |
| `sj3` | continuous | `(0,0,-1)` | 弧度 |
| `sj4` | continuous | `(0,0,1)` | 弧度 |
| `sj5` | continuous | `(0,0,1)` | 弧度 |
| `sj6` | prismatic | `(0,0,1)` | 米 |
| `sj7` | continuous | `(0,0,1)` | 弧度 |
| `xj1` | continuous | `(0,0,1)` | 弧度 |
| `xj2` | continuous | `(1,0,0)` | 弧度 |
| `xj3` | fixed | `(0,0,0)` | 固定 |

动态关节为 9 个：`sj1..sj7`、`xj1..xj2`；固定关节为 `sj0`、`xj3`。URDF 原点 `xyz/rpy` 保留在源文件中，未转换或重标定。

数值来源已区分：

- 离线零值：`A/ErcpApp/Interface/MsStatus.cs::GetJointValue` 在状态过期/无数据时返回 `sj[7]=0`、`xj[2]=0`、`v1=v2=0`；返回 `false`，因此零值不是实测在线姿态。
- 运行时旧值：`Motions.Cycles.cpp` 将 `u1..u7/d1/d2/P6` 转成 `status.jointData.sj1..sj7/xj1..xj2`；`v1/v2` 来自 `GetV1()/GetV2()` 并写入 `status.ct`。这些是旧工程来源，当前 B 的 `AxisPos[7]`、`AxisFromLeft[7]`、`arm_act_pos[5]` 不接入旧模型。
- 旧转换基准：`sj1=u1+4.12288e-3`，`sj2=u2-96.2203e-3`，`sj3=-(u3+18.2306°)`，`sj4=u4-1.47907°`，`sj5=u5+1.34638°`，`sj6=u6-5.50232e-3+P6e-3`，`sj7=u7-25.2479°`，`xj1=d1`，`xj2=d2-2°`；只记录基准，不在本步骤接入。
- 注释测试值：`Motions.Cycles.cpp` 约第 139-169 行的多组 `status.jointData` 赋值是注释代码，只能作为显式测试样例，不能当成实时值或默认姿态。
- 显示标定偏移：目前没有 B 侧显示标定偏移；旧常数只属于未来独立 DSA 状态适配边界，不能二次叠加。

## 4. UrdfMath 矩阵语义与最小复用范围

- `GetMatrixByAngle(x,y,z)` 使用 Eigen `R = Rz * Ry * Rx`。
- 4×4 托管数组按行布局传给 `vtkMatrix4x4.SetElement(i,j,...)`。
- `GetMatrixByAngle2` 将数组还原为 Eigen 矩阵，执行 `m = m1 * m2`，再按行布局写回；旧 `UrdfStruct` 的关节链路明确复用 `m1*m2` 顺序。
- 旧模型加载/移动只需要 `UrdfStruct.cs`、`Math4wpf.dll` 的 `Urdf.UrdfMath`、`Kitware.VTK` 和其匹配的原生 VTK 运行库；不需要把旧主端导航、PCL、深度学习等模块带入 B。
