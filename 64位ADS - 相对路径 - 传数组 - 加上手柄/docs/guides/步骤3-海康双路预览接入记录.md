## 实现边界

- 默认样例地址为旧工程的 `192.168.1.32:8000`、`192.168.1.64:8000`，通道 1、主码流 `stream=0`。
- `dwLinkMode=1`，表示向 SDK 请求 UDP；代码和界面不把它等同于已证明的实际 UDP 媒体。
- H.264 由设备当前码流编码配置决定，本步没有修改设备编码配置。
- 登录成功或预览句柄成功不会直接标记在线；只有回调收到媒体流数据后才显示“在线”。5 秒无媒体帧显示“过期”。
- 两路会话各自保存登录/预览句柄，失败或重连互不影响；停止顺序为停止预览、注销登录，最后由最后一个使用者清理 SDK。
- 不接入 `StatusFrame`、`RemoteRobotLink`、PLC、手柄或机器人控制协议。

## 离线检查

```powershell
dotnet build master/MasterConsole/MasterConsole.csproj -c Debug -p:Platform=x64 --no-restore
dotnet build master/MasterConsole/MasterConsole.csproj -c Release -p:Platform=x64 --no-restore
```

两种配置均构建通过，0 错误；只有既有 `_linkStatsText` 未使用警告。输出目录确认存在 `HCNetSDK.dll`、`PlayCtrl.dll` 和 `HCNetSDKCom\HCPreview.dll`。从 `C:\Windows` 工作目录以 `--sim` 启动 4 秒保持进程响应后正常关闭。
