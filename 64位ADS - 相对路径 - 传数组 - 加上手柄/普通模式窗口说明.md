# 普通模式窗口与本轮清理

## 窗口规则

- 普通导管的 axis1 窗口为距自身左限位 `[8,28] mm`。参数位于 `control_types.h` 的 `axis1_window_left_from_left_mm` 和 `axis1_window_right_from_left_mm`。
- 普通导管的 axis6 联动窗口随 axis5 当前实际位置刷新。axis6 与 axis5 **各自距左限位的位移之差**为 `[4,26] mm`，不是两个 PLC 绝对坐标直接相减。
- axis6 窗口由 `axis6_window_min_gap_from_axis5_mm = 4.0` 和 `axis6_window_size_mm = 22.0` 定义。
- 独立导丝在进入时建立并锁定 axis6 窗口。回退结束后，`motion_sync::rebase_axis6_after_return()` 复用该窗口，用当前 PLC 快照和已滤波手柄值重建跟随基准，不再次按 axis5 刷新窗口。
- axis6 到达触发边界后，后续同向有效输入仍可触发回退；零输入不触发。不要求跨入边界与手柄输入同拍发生。
- 普通导管回退保留 axis1、axis6 两条联动腿及 Axis1 基准重建；独立导丝回退只使用 axis6 腿及 Axis6 基准重建。
- 单手柄兼容只改变输入手柄来源，不改变上述窗口及回退规则。双物理手柄配置保留 587 导管、582 导丝角色。

## 本轮边界

本轮清理力过渡实验及协同模式的主循环、记录器、WPF 消费端残留，保留普通取消回退、PLC 握手、急停、屈曲恢复、普通力反馈和快退力保持。没有新增运动门控，没有修改 PLC 和既有记录数据。

`force.csv`、`motion.csv` 的格式保留；会话 JSON 删除实验专用 writer 及计数器字段，普通记录错误编号不重新编号。

## 配套升级与验证

C++ 与 WPF 必须成对更新：`VisState` 为 Pack=1、841 字节；历史命令编号 14–17、19、23 保留空洞，其他命令编号及 24 字节命令头不变。

离线测试位于 `tests/control_recovery_20260910`：

- `MotionSyncTest.vcxproj`：使用外设桩，不访问机器人，覆盖运动同步及窗口、回退基准。
- `VerifyProtocol.ps1`：逐字段核对 C++ 声明和已构建 C# 结构的类型、数组、布尔封送、偏移与命令编号。
- `UiSmoke.csproj`：使用模拟命名管道及离屏布局，不启动 ADS 后台。

上述编译及离线检查不代表临床验证。完整 Busy/Done 握手、导管双腿运动、连续导丝递送、回退后继续输入和实体按键仍需非临床台架验收。普通记录会话 JSON/CSV 的实际落盘也需独立验证。
