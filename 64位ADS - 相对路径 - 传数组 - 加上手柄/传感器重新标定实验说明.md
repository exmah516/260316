# 四路传感器重新标定实验说明

更新时间：2026-08-03  
适用程序：`ADS.exe --sensor-calibration`  
适用模块：`sensor_calibration_experiment.*`

## 1. 功能边界

该模式用于板卡返工后，对四路传感器当前原始计数重新建立与原标定数据的线性关系。程序读取 PLC 中的四路 `INT16` 原始值，同时参考原标定 CSV，最终在原标定目录生成一份 UTF-8 BOM 编码的 TXT 报告。

标定模式在手柄及正常控制流程初始化之前分流，具有以下边界：

- 只连接 ADS、读取传感器、计算拟合并写本地 TXT；
- 不初始化手柄，不启动 WPF、运动控制主循环或实验记录器；
- 不执行 PLC 状态或变量写入，不改变 PLC 运行状态；
- 不自动修改 PLC、`force_calibration.h` 或上位机中的现有标定参数。

PLC 必须已经处于 `RUN`。程序先尝试本地 AMS 路由的 851 端口，失败后再尝试既有远端路由；两者均失败时停止实验。

## 2. 固定通道映射

实验必须按以下物理传感器编号和 PLC 变量对应关系执行：

| 物理传感器 | PLC 变量 | 程序内目标通道 |
|---|---|---|
| 传感器 1 | `G.ft_1_value` | `ft_1_value` |
| 传感器 2 | `G.fn_1_value` | `fn_1_value` |
| 传感器 3 | `G.fn_2_value` | `fn_2_value` |
| 传感器 4 | `G.ft_2_value` | `ft_2_value` |

每次 ADS 采样会同步读取全部四路，但拟合时只使用当前物理传感器对应的目标通道。其他三路用于观察串扰和核对物理映射。

## 3. 原标定文件和路径查找

程序要求同一目录内存在以下四份原标定文件：

```text
传感器1标定数据.csv
传感器2标定数据.csv
传感器3标定数据.csv
传感器4标定数据.csv
```

CSV 必须使用 UTF-8 BOM 编码，并包含有效的 `斜率 (k)`、`截距 (b)`，以及 `0、2、5、10、20、50g` 六个重量点的均值和标准差。任一文件、字段或重量点缺失，程序都会在连接 PLC 前停止。

未指定 `--calibration-dir` 时，程序分别从当前工作目录和 `ADS.exe` 所在目录向上查找，最多检查 10 层。每一层都会检查：

1. 当前层本身是否直接包含四份 CSV；
2. 当前层下的 `力感测试程序加数据\传感器标定` 是否包含四份 CSV。

默认工程布局可自动定位到：

```text
D:\Work_files\Vessel intervention Robot\260316\力感测试程序加数据\传感器标定
```

若从其他目录启动或自动定位失败，应使用带引号的绝对路径：

```powershell
.\ADS.exe --sensor-calibration --calibration-dir "D:\Work_files\Vessel intervention Robot\260316\力感测试程序加数据\传感器标定"
```

## 4. 命令

### 4.1 离线数学自检

```powershell
.\ADS.exe --sensor-calibration --self-test
```

该命令不查找 CSV，也不连接 PLC。它使用合成数据检查正斜率、负斜率、退化输入拒绝、异常值剔除、样本不足、CSV 表头定位、跨度/噪声门槛、低 `R²`、兼容曲线展开和未完成报告的公式抑制。控制台最终应显示 `标定数学自检通过。`。

### 4.2 只校验原 CSV 和路径

```powershell
.\ADS.exe --sensor-calibration --validate-only
```

也可显式指定目录：

```powershell
.\ADS.exe --sensor-calibration --calibration-dir "D:\Work_files\Vessel intervention Robot\260316\力感测试程序加数据\传感器标定" --validate-only
```

该命令只读取并打印四份 CSV 的原曲线和六个参考均值，不连接 PLC。控制台最终应显示 `四份原标定 CSV 校验通过。`。

### 4.3 执行完整实机实验

```powershell
.\ADS.exe --sensor-calibration
```

若自动路径查找失败，增加 `--calibration-dir "<原标定目录>"`。在工程输出目录中，可直接运行例如：

```powershell
cd .\x64\Release
.\ADS.exe --sensor-calibration
```

使用 `--help` 或 `-h` 可查看简要用法，但两者必须放在 `--sensor-calibration` 之后。

## 5. 实验前准备

1. 关闭正在运行的正常 ADS 控制程序和 WPF 界面，避免多个程序同时读取或控制同一 PLC。
2. 确认机器人完全静止，运动执行器不会在实验期间动作，急停和现场防护有效。
3. 确认 PLC 已处于 `RUN`；标定工具不会替操作者切换 PLC 状态。
4. 准备经过确认的 `2、5、10、20、50g` 砝码。`0g` 点表示移除全部砝码。
5. 保持传感器安装姿态、受力方向、砝码作用位置和支撑方式与原标定一致。
6. 每次只给当前目标传感器加载，其他三只传感器始终空载；不要触碰线缆、台面或传感器安装件。
7. 先执行 `--self-test` 和 `--validate-only`，两项均通过后再开始实机实验。

本实验最大加载为 50g。不要使用超出该范围的砝码，也不要把冲击载荷代替静态加载。

## 6. 实机操作流程

程序按传感器 1、2、3、4 的顺序执行；每只传感器固定按 `0、2、5、10、20、50g` 的顺序采集。

1. 启动完整实验命令。程序先打印原标定目录、四路映射、原曲线和参考均值。
2. 阅读只读模式与现场安全提示，确认安全后按 `Enter`。在此处按 `Q` 会在连接 PLC 前退出，并生成带 `_未完成` 后缀的诊断报告。
3. 建链成功后，程序显示实际使用的本地 AMS 路由或远端 NetId。确认这是目标 PLC 后按 `Enter`；按 `Q` 中止并保存 `_未完成` 连接目标诊断报告。
4. 程序提示 `0g` 时，移除当前传感器上的全部砝码，确认其他三路空载且系统稳定，再按 `Enter` 开始采集。
5. 程序依次提示 `2g`、`5g`、`10g`、`20g`、`50g`。每次先放稳对应砝码，等待机械振动消失，再按 `Enter`。
6. 每个采集点完成后，控制台显示四路的均值、总体标准差和有效样本数，目标通道前带 `*`：
   - 按 `Enter` 接受本点；
   - 按 `R` 只重测当前重量点；
   - 按 `Q` 中止整个实验。
7. 一只传感器完成六点后，程序比较各通道 `|50g 均值 - 0g 均值|`。若主响应通道不是固定映射通道：
   - 核对砝码是否放在正确的物理传感器上、编号和接线是否正确；
   - 确认物理映射确实无误后按 `Enter` 保留警告并继续；
   - 按 `R` 重测该传感器的全部六点；
   - 按 `Q` 中止实验。
8. 程序计算拟合。若计数完全退化、无法形成数学拟合，只允许按 `R` 重测整只传感器，或按 `Q` 中止。
9. 若任一种拟合的 `R² < 0.98`，或计数跨度低于质量门槛，程序将结果标为“不建议使用，需复测”。可按 `R` 重测整只传感器；按 `Enter` 仅保留诊断结果并继续，不代表该曲线可投入使用。
10. 四只传感器全部完成后，程序关闭 ADS 连接并将最终 TXT 保存到原标定目录。

在等待放置砝码时只能按 `Enter` 或 `Q`；采集结束后的选择不区分大小写。控制台输入流意外关闭也按中止处理。

## 7. 采样和异常处理

每个重量点执行 100 次读取，使用单调时钟按 50 ms 截止时间调度，即目标为 20 Hz、5 秒。若 ADS 读取已经错过下一截止时间，程序从当前时刻重新建立后续节拍，不连续突发读取来追赶旧时间点，并在 TXT 中记录实际耗时、尝试频率和调度超期次数。实际尝试频率低于 `18 Hz` 时，本点禁止接受并必须重测或中止。每次使用一次 `ADSReadSum` 同步读取四路 `INT16`，因此四路统计来自同一组采样时刻。

四路分别进行如下处理：

1. 计算该通道本点全部成功样本的中位数；
2. 只保留与中位数相差不超过 300 counts 的样本；
3. 用有效样本计算均值和总体标准差，即标准差分母为有效样本数 `n`；
4. 拟合使用目标通道的有效样本均值。

ADS 读取失败不会用零值补齐，而是记为失败并减少四路的样本数。目标通道有效样本少于 80 时，该点不能接受，必须按 `R` 重测或按 `Q` 中止。其他通道少于 80 不会强制重测，但会保留在统计中，应结合通道核对结果检查。

## 8. 三类线性公式

设：

- `current_raw`：板卡返工后，当前 PLC 目标通道的原始计数均值；
- `old_raw`：原标定时的原始计数；
- `old_k`、`old_b`：原 CSV 中的斜率和截距；
- `a`、`c`：当前计数到原标定等效计数的拟合参数；
- `p`、`q`：当前计数到物理力的直接拟合参数。

### 8.1 等效原计数补偿

用当前六点计数均值作为输入，以原 CSV 同重量点的计数均值作为目标：

```text
old_equivalent = a * current_raw + c
```

这是保持原系统行为的首选方案。它先把返工后的计数换算到原传感器计数域，再复用原有标定链。

### 8.2 兼容原标定的力

原标定曲线为：

```text
F_old(N) = old_k * old_raw + old_b
```

把 `old_equivalent` 代入原曲线：

```text
F_compatible(N) = old_k * old_equivalent + old_b
                = (old_k * a) * current_raw + (old_k * c + old_b)
```

TXT 同时给出展开后的当前计数一次曲线，便于检查或在单级计算链中使用。

### 8.3 独立物理标定

直接以砝码对应的标准重力作为目标：

```text
force_target(N) = weight_g / 1000 * 9.80665
F_direct(N) = p * current_raw + q
```

该曲线不依赖原计数均值，可作为独立对照，但它不以“保持返工前系统行为”为目标。未经完整评审，不应直接用它替换既有系统标定链。

斜率可以为正，也可以为负；符号由传感器方向、接线和安装决定。不要只因出现负斜率就手工取反，应结合原曲线方向、加载方向、主响应通道和拟合质量判断。

## 9. 拟合质量和采用规则

等效原计数拟合与独立物理拟合均输出：

- `R²`；
- RMSE；
- 最大绝对残差；
- 当前计数跨度；
- 六个重量点的预测值和预测误差。

等效计数拟合的残差和 RMSE 单位为 counts；直接力拟合的单位为 N。任一种拟合 `R² < 0.98` 时，TXT 的质量结论为 `不建议使用，需复测`。

输入跨度还必须同时满足：六点当前计数的最大值减最小值至少为 `1 count`，且该跨度除以目标通道六点中的最大总体标准差至少为 `5`。未通过时同样标为“不建议使用，需复测”；若计数完全退化到无法拟合，则必须重测或中止。所有公式只在本次 `0–50g` 以及报告列出的 `current_raw` 最小/最大范围内经过验证，范围外属于未验证外推。

完成实验后，应优先采用：

```text
current_raw -> old_equivalent -> 原有 old_k / old_b 标定链
```

若在 PLC 中实现，计算过程使用 `LREAL`。只有接口必须回写整数时，才在最后一步四舍五入，并限幅到 `INT16` 的 `[-32768, 32767]`。不要在中间步骤提前转为 `INT`，否则会引入量化误差。

## 10. 输出 TXT

完整实验保存为：

```text
<原标定目录>\传感器重新标定_YYYYMMDD_HHMMSS.txt
```

同名文件已存在时会追加 `_001`、`_002` 等序号，不覆盖旧文件。文件编码为 UTF-8 BOM，包含：

- 完成状态、生成时间、原标定目录、实际 ADS 连接方式和采样配置；
- 固定映射、四份源 CSV 路径及原 `old_k / old_b`；
- 每只传感器六个重量点的四路均值、总体标准差、中位数、有效/总样本数、ADS 失败次数、实际耗时、尝试频率和调度超期次数；
- `50g-0g` 主响应通道及人工确认结果；
- 等效原计数、兼容原标定力、独立物理标定三类公式；
- 两种拟合的质量指标、跨度/噪声比、验证范围及逐点预测误差；
- `可用` 或 `不建议使用，需复测` 的质量结论；
- 优先使用等效计数补偿及 `LREAL` / `INT16` 处理建议。

TXT 是诊断和实施依据，不代表程序已经修改任何运行参数。应用新曲线前应保留原配置，并由操作者明确选择实施位置。

## 11. 失败和中止处理

| 情况 | 程序行为 | 处理建议 |
|---|---|---|
| 自动定位失败 | 连接 PLC 前停止，不生成 TXT | 用 `--calibration-dir` 指定包含四份 CSV 的目录 |
| CSV 缺失、非 UTF-8 BOM、字段或重量点无效 | 连接 PLC 前停止，不生成 TXT | 修复或恢复原 CSV，再运行 `--validate-only` |
| PLC 非 `RUN` | 显示当前 ADS 状态并断开，不替操作者切换状态；若两种路由均不可用则保存 `_未完成` 连接诊断 TXT | 在 TwinCAT 中确认现场安全后切到 `RUN` |
| 本地和远端 ADS 均连接失败 | 不采集数据，保存 `_未完成` 连接诊断 TXT | 检查 TwinCAT Router、AMS 路由、端口 851 和 PLC 在线状态 |
| 实际 ADS 连接目标未获人工确认 | 关闭连接并保存 `_未完成` 连接目标诊断 TXT，退出码为 3 | 核对本地 Runtime 或远端 NetId 后重新启动 |
| 单点目标通道有效样本少于 80 | 本点禁止接受 | 检查 ADS 稳定性和接线，按 `R` 重测 |
| 单点实际尝试频率低于 18 Hz | 本点禁止接受 | 检查 ADS 超时、Windows 系统负载和路由稳定性，按 `R` 重测 |
| 主响应通道与固定映射不同 | 要求人工确认、整只重测或中止 | 优先检查物理编号、加载位置和 PLC 符号映射 |
| 当前计数完全退化或拟合失败 | 该传感器不能形成完整曲线 | 重测全部六点；确认砝码确实逐级加载 |
| 计数跨度 `< 1 count` 或跨度/最大标准差 `< 5` | 结果明确标为“不建议使用，需复测” | 检查传感器增益、接线、机械装夹和采样噪声 |
| 任一种 `R² < 0.98` | 结果明确标为“不建议使用，需复测” | 不投入控制系统，重新检查装夹、稳定时间和加载方向 |
| 实验开始后按 `Q` 或输入流关闭 | 保存带 `_未完成` 后缀的诊断 TXT，退出码为 3 | 仅用于排查，不得作为正式标定结果 |
| 初始安全确认处按 `Q` | 保存带 `_未完成` 后缀、且不含可部署曲线的诊断 TXT，退出码为 3 | 排除现场问题后重新启动 |
| ADS 只读连接失败 | 不采集数据，保存带 `_未完成` 后缀的连接失败诊断 TXT，退出码为 2 | 检查 TwinCAT Router、AMS 路由、端口 851 和 PLC `RUN` 状态 |
| TXT 创建或写入失败 | 控制台报告写入错误 | 检查目录权限、磁盘空间和文件占用 |

未完成文件命名示例：

```text
传感器重新标定_YYYYMMDD_HHMMSS_未完成.txt
```

其状态行写明 `未完成，禁止作为正式标定结果使用`。文件只保留中止前已接受的数据；只要四路实验整体未完成，程序就统一抑制全部拟合公式、`可用` 结论和部署建议，即使前面的某一路已经完成六点采集也不例外。

## 12. 实机验收清单

完成一轮实验后，按以下要求验收：

1. `--self-test` 全部显示 `[PASS]`，`--validate-only` 成功读取四份原 CSV。
2. 实验期间正常 ADS 控制程序和 WPF 均未运行，机器人始终静止，PLC 保持 `RUN`。
3. 四只传感器均按 `0、2、5、10、20、50g` 完成，未测三路全程空载，姿态和受力方式与原标定一致。
4. 每个目标通道每点至少 80 个有效样本；标准差和 ADS 失败次数无异常突增。
5. 四只传感器的主响应通道均与固定映射一致；若曾人工确认不一致，必须在采用结果前再次核对接线和 PLC 符号。
6. 等效计数和直接力两种拟合均未出现 `R² < 0.98`，且逐点误差、残差和计数跨度符合实验要求。
7. 最终文件名不含 `_未完成`，报告状态为 `完成`，四只传感器的采集状态均为 `完整`。
8. 实施时优先使用 `old_equivalent` 补偿，并在离线或受控状态下逐点回放验证 `0、2、5、10、20、50g`；验证通过前不要进入机器人正常运动实验。

当前软件侧可验证命令、CSV 解析、异常值处理和拟合逻辑；ADS 实时读取、实际噪声、主响应通道和最终曲线仍必须通过上述实机砝码实验验收。
