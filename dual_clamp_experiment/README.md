## PLC接口

配套解决方案为 `D:\Work_files\Vessel intervention Robot\260316\250902\250902.sln`。其 `250902\Untitled2` 中的 `MAIN.TcPOU` 调用独立的 `ProgrammedDeliveryExperiment` 和 `ExperimentRecorder` 功能块。当前源码入口以PLC工程为准。当前模式1为导管、2为导丝、4为外源验证，使用 `G.program_test_*` 接口，不依赖旧 `dual_clamp_*` 实验接口。
PLC任务周期为1 ms；长时间记录使用2个512点分块交替传输，32768点数组仅作为PLC短时诊断缓存。采样包含运动状态、电缸命令和四路力感原始值；C++按“取零→0~50 g斜率→机构安装校正”生成校正量，并在CSV中追加N、N·mm和串扰解耦字段，另生成`events.csv`。

操作顺序为“连接PLC”→“启动自检”→“等待自检完成”→“选择模式”→“准备定位”→“力感取零点”→“开始测试”。启动自检直接发送明确请求，不弹确认窗口，不自动准备或开始实验。自检完成后轴2、轴7按原程序绝对定位到0度。导管默认轴1距左限位23 mm、触发位置3 mm；导丝可设置轴5、轴6初始位置和轴6触发位置；各模式可设置对应夹爪参数。外源验证流程见 `外源验证模式说明.md`。

旧模式只选择运动端：选择轴1时轴6为固定端，选择轴6时轴1为固定端。导管、导丝模式继续由PLC自动递送：导管操作轴1、轴2，导丝操作轴5、轴6、轴7；每周期按前向触发、释放、回退、重新夹紧执行，最后按设定距离执行最终前向段。外源验证模式仅正常递送阶段接受手柄，释放、回退、重夹紧仍由PLC执行，末周期不追加前向运动。导管模式可选电缸1是否参与电缸2的同步配合，导丝模式可选电缸3是否参与电缸4的同步配合；默认开启，关闭时对应电缸保持400。实验进入完成、中止或错误状态后，PLC和上位机自动停止实时记录并归档，不需要再次点击中止或准备。实时状态和曲线按当前模式只显示相关轴与相关力感通道；导管、导丝的`fn`/`ft`单位均为N，外源曲线为轴向力N及扭矩N·mm；CSV中的扭矩字段单位为N·mm，重力补偿暂不执行。

## 导管前进暂停（2026-10-09）

导管模式可勾选“启用前进暂停”，设置从每段起点前进的距离及停留秒数（默认10 mm、3 s）。每周期和经过暂停点的最终前向段均停稳后计时，再自动继续；停留期间保持夹持和采集。详见 [更新与验证说明](tools/FORWARD_PAUSE.md)。
