# 换手冻结显示

仅处理导管模式的轴1、测量通道1。界面右侧轴向图图例中的“换手冻结显示”默认关闭，勾选后黑线同时显示轴向和ft冻结结果；原始实测作为比较曲线保留。后端持续计算并记录派生列，开关只控制显示。PLC、运动指令、旧动力学模型及手柄反馈不使用冻结结果。

## 固定参数

| 参数 | 值 |
|---|---:|
| 位置搜索窗，距离本轮触发点 | 5 至 2 mm |
| 稳定性窗口 | 连续50帧，PLC帧间隔1000 μs |
| 稳定性判据 | 轴向力峰峰值不超过0.1 N |
| 无稳定窗时的采样起点 | 首个剩余距离不超过2 mm的点 |
| 取平均的空间跨度 | 起点之后1 mm |
| 采样点数 | 每0.05 mm首次越过时取真实帧，共20帧 |
| 冻结开始 | Phase4跳到Phase5的第一帧 |
| 冻结结束 | 下一段Phase4或Phase9从该段起点实际前送满2 mm |

轴向和扭矩使用完全相同的20个采样索引。稳定性仅针对轴向力，不保证扭矩同样稳定。方向沿用本项目的导管前送约定：距左限位坐标递减。开始和恢复时直接切换，不增加渐变或滤波；正常前送的其他时段保持实测值。

每轮必须重新采集参考。数据无效、样本序号或1 kHz时间戳不连续、取零、重新准备、启动、中止均清除状态；输入一次跨过多个未采样空间格时，本轮参考标记无效。没有有效参考的换手段不输出冻结曲线，不借用上一轮均值。完成、错误或中止阶段结束曲线，不画出假恢复。

## 代码接口

`HandoverHold.h` 包含固定参数、逐帧状态机及CSV/元数据序列化。`ProgrammedDeliveryController::poll_stream_locked` 在标定后将原始标定通道、PLC时间戳、相对位置、实际阶段送入状态机，跨512点块保持状态。批量导出路径也调用同一状态机。

`samples_1khz.csv` 在原有列末尾增加以下字段：

| 列 | 含义 |
|---|---|
| `handover_fn_N` | 显示用轴向力，单位N |
| `handover_torque_Nmm` | 显示用扭矩，单位N·mm |
| `handover_valid` | 本帧冻结/实时比较曲线可用；无效数值留空 |
| `handover_reference_valid` | 已完成本次参考取样 |
| `handover_holding` | 本帧正在保持常数 |
| `handover_source` | `none`、`stable_window`或`forced_at_2mm` |
| `handover_status` | 实时、搜索、取样、参考就绪、冻结、恢复、缺参考、无效、断样、结束或空间采样不足 |
| `handover_sample_count` | 当前参考已采集的帧数 |
| `handover_reference_start_index` | 参考空间窗的起始样本序号 |

`experiment.json` 的 `handover_hold` 保存本次算法参数和版本。CSV扭矩不做二次安装增益；界面ft使用既有37 mm力臂换算为N。导丝新记录保留同名尾部列但其冻结值无效，外源和旧双机构记录格式保持原样。

曲线管道保留旧18字段前缀，追加7字段：轴向、ft、有效性、参考有效性、冻结标记、来源编号、状态编号。新界面兼容8、12、18、25字段；旧界面需要与新后端一起更新。

## 重现验证

在项目目录执行：

```powershell
./tools/build_handover_tests.ps1
python -B tools/replay_handover_hold.py
./tools/verify_handover_ui.ps1
```

UI验证需要先编译 `DualClampExperiment.sln` 的 Debug/x64 配置。回放脚本使用现有Python、NumPy、Pandas和Matplotlib；`--figure-tools` 可指定已有的图形质量检查脚本目录。两类回放入口均不连接ADS、不启动机器人。

输出目录为 `analysis/handover_hold_20261013`。C++生产算法与独立按段求解逐点核对，并保存原始CSV的前后SHA-256。`REPORT.md`包含真实结果；恢复跳变不做平滑、不剔除首轮。

冻结期的平坦只表示显示保持，期间真实外力变化会被隐藏。此版本没有验证实机效果，也没有实现卡尔曼滤波或物理扰动抵消。
