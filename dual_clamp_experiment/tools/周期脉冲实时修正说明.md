# 周期脉冲实时修正与位置记录

适用范围：导管、导丝程序递送实验。更新日期：2026年9月11日。

## 使用

界面默认勾选“周期脉冲修正”，同时作用于当前模式的fn、ft曲线。取消勾选显示原始曲线。显示选择不影响后台计算、采样记录、电机指令或力反馈。

后台先观察三个已经回落、周期一致的候选事件，之后才替代符合该周期及双通道形状的事件。最初三个事件、不符合规则的事件及不能及时确认的起始点保留原值。导管与导丝每次切换均重新观察，不沿用另一侧的周期状态。

识别后使用最近的、位于异常开始前的有效fn/ft样本对。连续异常期间保持同一对历史值，并记录其来源序号和实际时间间隔。出现第一个恢复到参考带的样本就放行当前值，不额外等待三个点；随后收集恢复证据仅用于学习下一次周期。

超过100 ms仍未恢复，停止替代、清除周期确认状态，并放行原始值。切换模式、重新准备、实验开始、取零、数据断续或无效输入时重置。未识别的疑似尖峰不会被回头改写。

## 因果规则

规则在传感器整数计数层判断，力输出仍沿用现有取零和标定链：

- ft在最多两个记录点内上升至少35 counts。
- 相对前100～10 ms的ft中位数，正向偏离为43～180 counts。
- 近几个记录点内fn跳变至少23 counts。
- 参考区间至少有40个有效点，ft的10%～90%分位范围不超过10 counts。
- 能在最近3 ms内找到ft位于参考±8 counts的前序有效样本对。
- 学习事件需在100 ms内回落，并随后连续三个点处于参考±8 counts内。
- 三个历史事件之间的周期均在2.2～2.55 s，两个间隔相差不超过130 ms，才确认周期。
- 替代还要求当前事件处于历史预测周期±130 ms内。周期信息过期后重新观察。

导丝目前使用同一计数级脉冲形状，必须独立完成周期确认。已有真实回放证据来自导管模式，导丝仅完成合成计数及界面、标定路径测试。

算法使用固定128点缓冲，只在候选事件处计算参考中位数。逐点运算没有动态内存分配、额外通信或未来样本等待。原有512点分块采集和界面刷新机制保留。

因果方法无法在跳变刚发生时知道它随后一定会恢复，因此实时结果不会与离线清理完全相同。如果真实物理事件与已确认干扰具有相同的双通道形状和周期，仍存在误判可能；原始值和替代标记用于审查这种情况。保持值是缺失测量的替代，不代表异常期间的真实外力。

## 记录

原始力、标定力及原有causal_force.csv保持原始输入语义。samples_1khz.csv末尾增加：

| 字段 | 含义 |
|---|---|
| fn_despiked_N、ft_despiked_N | 当前模式的脉冲替代后力值 |
| pulse_valid | 该次处理输入有效 |
| pulse_replaced | 当前样本是否用历史值替代 |
| pulse_source_index | 输出所用原始样本序号；正常时等于当前序号 |
| pulse_age_us | 当前时间减来源样本时间 |
| pulse_status | 0正常、1观察候选、2替代、3恢复、4超时放行、5无效、6断续重置、7形状不符放行 |
| pulse_locked | 已确认历史周期 |
| pulse_compute_us | 本次识别及力值换算的计算耗时 |

输入无效时修正力字段留空，pulse_valid=0。原始CSV中的fn1_raw/ft1_raw曾误写导丝侧数值，本次修复为实际导管侧原始计数；没有更改既有文件。

模型曲线在勾选修正时显示“修正力减原模型预测”。causal_force.csv继续保存原始力的模型结果，修正后的模型结果可由fn_despiked_N减fn_prediction_N计算。模型2改为使用修正后的力输入，其CSV增加实际输入值及替代标记，元数据注明输入来源；它仍为目标效果示意。

## 位置与实验条件

原有采集块已经包含轴1、2、6、7的同步位置。本次在两种模式中都增加：

- record_axis1_nc_mm、record_axis6_nc_mm：记录块中的NC直线坐标。
- record_axis2_nc_deg、record_axis7_nc_deg：记录块中的NC旋转角度。
- axis1_from_left_mm、axis6_from_left_mm：当前NC直线坐标减去实验开始前冻结的左限位NC坐标。
- position_reference_valid：左限位有效且实验中未发生参考变化。无效时两列相对坐标留空。

左限位原值和定义保存于experiment.json。左限位有效标志通过既有实时状态批量读取一并取得，不增加每个采样点的ADS调用；坐标只做减法，不重新读取轴位置。相对左限位的跨上电一致性取决于重新寻参的重复精度。

轴2、7是旋转轴。当前PLC自检将它们移动到NC角度零点，没有建立物理旋转限位或编码器基准的独立验证。因此保存实际角度，但不把它们称为已经保证跨上电一致的机械零位。

experiment.json还保存前向及回退速度、加速度、减速度、Jerk、轴1准备/触发位置及等待时间，便于区分每次实验条件。

## 验证结果

七份2026年9月11日07:49:59～07:55:39真实记录共253,598点。C++逐点因果回放替代892点，全部位于此前离线规则的异常标记范围内。离线保留的特征点没有被替代；这项检查使用离线标记作参照，不是独立传感器真值。

已检查：只用历史来源、修改未来数据不改变过去结果、重复输入不重复更新、断流及无效重置、长异常超时放行、正常点不变、两种模式CSV表头与数值、坐标有效性和原始通道保存。

本机Debug算法测试的单点99%分位约0.2 μs；系统调度会产生少量更长调用。每侧12,000点的离线记录测试约0.31 s完成，512点追加批次约14 ms以内。上述为本机离线测量，不包含真实ADS通信等待，不能当作端到端实时延迟保证。

新增字段使文件略增大，保持原有1 ms采样序号与时间戳。实际新实验应继续检查sample_gap、record_overflow、ADS状态和计算耗时。构建、回放与文件测试不连接硬件，也不启动机构运动。

## 约10 mm处抖动的含义

此前不同加速度组的明显抖动起点位移中位数约为9～11 mm。这提示应检查位置、速度及运动历史的关系，但尚不能定位某个部件故障：各次起点相同，使绝对位置与累计位移重合。

保持速度、加速度、Jerk和行程不变，将起点平移一段已确认可行的距离，可以区分“经过同一距左限位位置时出现”和“从起点移动相同距离后出现”。本次增加的坐标记录正用于这种比较。
