# 双机构夹持扰动实验程序使用说明

## 1. 文档目的

本程序用于介入机器人导管、导丝程序递送测试，以及原有双机构夹持对照实验。程序由 TwinCAT PLC、C++ ADS 后端和 WPF 可视化界面组成，能够显示实验阶段和相关轴的运动状态，并记录轴位置、速度、加速度、电缸控制量、轴向力和切向力。

实验时应使器械保持水平、平直，不接触血管模型。取力感零点和正式实验期间，相关机构应保持静止或按照程序运行。真实机构实验前必须确认急停、限位、夹爪和器械安装状态正常。

本文档描述当前程序的实际使用方式，不把尚未完成或尚未验证的功能当作可用功能。

## 2. 启动程序

建议按以下顺序启动：

1. 在 TwinCAT 中启动 PLC 运行。
2. 等待 PLC 自动执行自检。当前自检由 PLC 上电后的程序自动触发，上位机没有“执行自检”按钮，也不会主动发送自检请求。
3. 启动 C++ 后端程序和 WPF 界面。使用 Visual Studio 本地 Windows 调试器时，应按解决方案中的启动配置启动相应项目。
4. 在界面顶部确认“UI 管道”已连接、“ADS”显示正常（Port 851），并确认“PLC 自检：已完成”。
5. 选择实验模式后，再进行参数设置和准备定位。

PLC 自检中，轴1、轴3、轴5、轴6执行左限位相关自检，轴2和轴7按原程序执行角度归零，轴4不参与实验运动。自检完成后，PLC 建立左限位基准，界面只读取自检状态和左限位数据。

## 3. 实验模式

界面“实验模式”下拉框包含三项。模式切换应在当前实验已完成、已中止或尚未开始时进行；如果当前记录尚未归档，程序可能拒绝切换模式。

### 3.1 旧双机构对照模式

该模式沿用原有双机构实验逻辑，界面只需要选择“运动端”：

- 选择“轴1运动”时，轴6保持固定，电缸4作为固定端夹紧。
- 选择“轴6运动”时，轴1保持固定，电缸2作为固定端夹紧。

旧模式参数包括轴1和轴6距左限位位置、轴2和轴7角度、回程距离、回程速度、回程加速度、回程减速度、回程 Jerk，以及回程后“夹紧后静止”或“夹紧后输送”的恢复方式。该模式继续执行原有的基准采样、运动端释放、回程、重新夹紧和恢复流程。

旧模式面板下还包含“电缸手动控制”和“独立数据记录”。它们不是第四个实验模式，也不会改变三个模式下拉框的内容。

#### 电缸手动控制

电缸1～4可以分别设置开值、闭值和启用状态，默认值为：电缸1开1000/闭0，电缸2开0/闭600，电缸3开400/闭50，电缸4开0/闭500。点击某一路的“开”或“闭”按钮，只下发该路对应的输出值，不发送任何轴运动指令。

电缸手动按钮只有在 ADS 已连接、PLC 自检完成且旧模式和程序模式都没有处于运动或夹爪切换阶段时可用。PLC 自检尚未完成时，按钮保持禁用，但不影响独立数据记录。实验准备或运行后，手动电缸控制会被撤销；停止手动控制后，PLC 恢复标准空闲电缸输出。

#### 独立数据记录

独立数据记录只用于旧模式面板。它与“开始测试”不同：点击“开始记录”只启动采样和实时写盘，不启动轴运动、准备定位或夹爪流程。只要 ADS 已连接、旧双机构正式实验没有在运动，就可以开始记录，不要求 PLC 自检完成、准备定位完成或力感取零完成，因此也可以用来记录自检过程、空闲状态和手动电缸开闭过程。

开始记录前，在字段列表中至少勾选一个实际数据字段。轴1/2/5/6/7的位置、速度、加速度，电缸1～4输出，以及四路原始力感和去零力感均可单独勾选；采样序号、PLC时间、阶段和事件序号始终写入。使用“全选”或“清空”可以批量修改选择。独立记录 CSV 只包含勾选的实际字段。

独立记录的操作顺序为：输入记录名称后缀、勾选字段、可选地点击“力感取零点”、点击“开始记录”，需要结束时点击“停止记录”。停止时程序会关闭 PLC 独立记录使能、读取最后一个不满512点的数据块、等待写盘队列完成并生成最终 `experiment.json`。如果未取零，原始力感仍可记录，去零字段留空；取零完成后才会写入去零值。独立记录不与旧模式正式实验并行，旧模式正式实验运行时仍使用原有自动记录流程。

### 3.2 导管程序递送测试

该模式由程序控制，不使用手柄。轴1负责直线递送，轴2负责周向角度；其他轴不参与该模式的程序递送运动。

轴1位置以左限位为基准：

```text
准备位置：界面设置，默认距左限位 23 mm
触发位置：界面设置，默认距左限位 3 mm
```

导管模式的一个周期为：

```text
轴1到设定准备位置
→ 基准采样
→ 轴1前向运动到设定触发位置
→ 运动端释放
→ 轴1回退到设定准备位置
→ 运动端重新夹紧
```

前向运动的目标位置变小，回退运动的目标位置变大。设置多个周期时，前 N-1 个周期只执行上述流程；最后一个周期重新夹紧后，再执行一次“最终前向距离”，完成后不再触发下一次回退。

界面参数为轴1准备位置、轴1触发位置、轴2角度、往复夹持次数、最终前向距离、释放后等待时间、重新夹紧后等待时间，以及前向/回退速度、加速度、减速度和 Jerk。准备位置必须大于触发位置，触发位置不得小于 `0 mm`；最终前向距离不得超过“准备位置 - 触发位置”。

### 3.3 导丝程序递送测试

该模式由程序控制，不使用手柄。轴5为导丝参考轴，轴6为直线递送轴，轴7负责周向角度；轴5在整个测试周期中保持准备位置。

界面只输入轴5距左限位的位置，轴6由程序自动计算：

```text
轴6准备位置 = 轴5位置 + 21 mm
轴6触发位置 = 轴5位置 + 1 mm
```

例如，轴5设置为 `430 mm` 时，轴6准备位置为 `451 mm`；轴5设置为 `649 mm` 时，轴6准备位置为 `670 mm`。轴5输入范围为 `0~649 mm`，不能使轴6目标超过 `670 mm`。

导丝模式的一个周期为：

```text
轴5保持设定位置，轴6到轴5+21 mm
→ 基准采样
→ 轴6前向运动到轴5+1 mm
→ 运动端释放
→ 轴6回退到轴5+21 mm
→ 运动端重新夹紧
```

最后一个周期重新夹紧后，轴6再向左执行一次最终前向距离，完成后不再触发回退。界面参数包括轴5位置、轴7角度、往复夹持次数、最终前向距离、释放后等待时间、重新夹紧后等待时间，以及前向和回退运动参数。最终前向距离限制为 `0~20 mm`。

两类等待时间的单位均为毫秒，允许范围为 `0~60000 ms`，默认值均为 `150 ms`。准备定位前和到达触发位置后的释放命令使用“释放后等待”；准备定位完成后和每次回退完成后的夹紧命令使用“重新夹紧后等待”。等待结束前不会下发下一段轴运动。

## 4. 准备定位与力感取零

每次实验建议按照以下顺序操作：

```text
选择实验模式并设置参数
→ 点击“准备定位”
→ 等待界面显示准备完成
→ 确认器械水平、平直且不接触模型，机构保持静止
→ 点击“力感取零点”
→ 等待“力感零点：已完成”
→ 点击“开始测试”
```

“准备定位”会将相关轴移动到当前模式规定的位置，并下发夹持组合。准备未完成、PLC 自检未完成或 ADS 未连接时，不能开始取零或实验。

点击“力感取零点”后，正式实验和程序递送模式要求已经准备定位；旧模式下的独立取零不要求自检或准备定位，但仍要求 ADS 已连接且旧实验没有运动。PLC 连续采集约 1 秒、约 1000 个 1 ms 采样点，计算 `fn1`、`ft1`、`fn2`、`ft2` 四路零点均值和标准差。取零期间不应让机构运动，也不应让器械接触外部物体。

程序不修改 PLC 中的原始力感变量。正式数据中同时保存原始值和去零值，去零值按以下方式得到：

```text
去零值 = 原始值 - 对应通道零点均值
```

界面曲线在取零完成后显示机构安装校正后的增量物理量：`fn1/fn2` 为轴向力，单位 `N`；`ft1/ft2` 为切向力，单位 `N`，不显示扭矩。未完成取零时，界面显示“未取零”，不会把原始 ADC 计数显示成物理单位。

程序采用统一的两级标定链。每个通道先用当前零点扣除后的 ADC 计数乘以 0~50 g 传感器斜率，再执行机构安装后的校正：

```text
sensor_delta_N = sensor_slope × (raw_count - zero_count)
fn_cal_delta_N = 1.913504 × sensor_delta_N
fn_cal_abs_N   = fn_cal_delta_N + 0.183108
torque_cal_delta_Nmm = 18.440851 × ft_sensor_delta_N
torque_cal_abs_Nmm   = torque_cal_delta_Nmm + 0.020906
ft_cal_delta_N = torque_cal_delta_Nmm / 37
ft_cal_abs_N   = torque_cal_abs_Nmm / 37
```

实时界面使用 `fn_cal_delta_N` 和 `ft_cal_delta_N`，不叠加固定截距；CSV 同时保存增量值和带截距绝对值。导管侧 0~50 g 斜率为 `fn1=0.000614437208097`、`ft1=0.000703683250522 N/count`；导丝侧使用 2026 年 8 月 29 日标定的 `fn2=0.001134444473`、`ft2=0.000133373639 N/count`。CSV 中扭矩字段单位为 `N·mm`。

CSV 还会对机构校正后的 `F (N)` 和 `T (N·mm)`执行串扰解耦：

```text
F_dec =  0.996063 × F_cal + 0.037854 × T_cal
T_dec = -0.103597 × F_cal + 0.996063 × T_cal
```

解耦同时计算增量值和带截距绝对值，仅写入 CSV，不用于实时显示。本程序暂不执行重力补偿，只记录轴2/轴7角度；`experiment.json` 中 `gravity_compensation_applied` 固定为 `false`。

导丝侧实时物理量按以下公式计算：

```text
fn2_N = 0.001134444473 × (fn2_raw - fn2_zero)
ft2_N = 0.000133373639 × (ft2_raw - ft2_zero)
```

这两项标定分别来自 `传感器3标定数据_20260829_163043.csv` 和 `传感器4标定数据_20260829_163556.csv`。由于每次实验会现场取零，换算使用“原始计数减当前零点”后乘斜率，不再叠加标定拟合中的固定截距。

以下情况会使已有零点失效，需要重新取零：PLC 重启、ADS 重连、切换实验模式、重新准备定位或再次点击取零按钮。

## 5. 开始、运行、中止和自动保存

点击“开始测试”后，PLC 按所选模式执行程序流程。正式实验开始前必须满足：ADS 已连接、PLC 自检完成、准备定位完成、取零已完成、参数有效。旧模式面板中的“开始记录”不受这些正式实验条件限制，具体规则见上文“独立数据记录”。

实验运行过程中，PLC 将采样数据写入双缓冲块，C++ 后端持续读取数据块并由独立写线程写入 CSV。实验不依赖一次性读取整个 PLC 数组，因此长时间实验可以持续记录；但如果 PLC 分块溢出、ADS 读取失败、样本序号不连续或写盘失败，程序会请求中止并保留已经写入的数据。

点击“中止”后，程序请求 PLC 停止当前运动，进入中止状态并停止本次记录。已经写入的数据不会自动删除。实验进入完成、中止或错误状态后，后端会自动读取最后一个分块、刷新写盘队列、关闭 CSV 并生成最终 `experiment.json`，不需要再点击保存按钮。

当前实现中，记录目录和三个 CSV 文件可能在点击“力感取零点”时就已经创建，因为取零原始数据也需要保存；正式实验开始后，数据继续写入同一目录。独立记录在取零时会先创建临时记录目录，点击“开始记录”时按当前字段选择重建样本表头。保存后缀在“准备定位”或“开始独立记录”时从界面的名称输入框下发，记录开始后不能修改。

## 6. 实验数据文件

记录目录默认位于：

```text
DualClampExperiment.exe 所在目录\records\YYYYMMDD_HHmmss_保存后缀\
```

如果同名目录已经存在，程序会自动追加序号，避免覆盖已有数据。保存后缀会清除 Windows 文件名不允许的字符，首尾空格会被去除，最长 64 个字符；为空时使用 `experiment`。

每个记录目录通常包含：

### `samples_1khz.csv`

正式实验采样数据。所有模式保留原有字段和顺序，并在末尾追加两级标定、扭矩、串扰解耦和旋转角度字段。所有模式都包含采样序号、PLC 时间、阶段和事件序号。

导管模式主要字段为：

```text
sample_index, plc_time_us, phase, event_sequence, cycle_index
axis1_pos_mm, axis1_vel_mm_s, axis1_acc_mm_s2
axis2_pos_deg, axis2_vel_deg_s, axis2_acc_deg_s2
cylinder1_cmd, cylinder2_cmd
fn1_raw, ft1_raw, fn1_zeroed, ft1_zeroed
fn1_sensor_N, ft1_sensor_N
fn1_cal_delta_N, fn1_cal_abs_N, ft1_cal_delta_N, ft1_cal_abs_N
torque1_cal_delta_Nmm, torque1_cal_abs_Nmm
fn1_decoupled_delta_N, torque1_decoupled_delta_Nmm
fn1_decoupled_abs_N, torque1_decoupled_abs_Nmm, axis2_angle_deg
```

导丝模式主要字段为：

```text
sample_index, plc_time_us, phase, event_sequence, cycle_index
axis5_pos_mm, axis5_vel_mm_s, axis5_acc_mm_s2
axis6_pos_mm, axis6_vel_mm_s, axis6_acc_mm_s2
axis7_pos_deg, axis7_vel_deg_s, axis7_acc_deg_s2
cylinder3_cmd, cylinder4_cmd
fn2_raw, ft2_raw, fn2_zeroed, ft2_zeroed
fn2_sensor_N, ft2_sensor_N
fn2_cal_delta_N, fn2_cal_abs_N, ft2_cal_delta_N, ft2_cal_abs_N
torque2_cal_delta_Nmm, torque2_cal_abs_Nmm
fn2_decoupled_delta_N, torque2_decoupled_delta_Nmm
fn2_decoupled_abs_N, torque2_decoupled_abs_Nmm, axis7_angle_deg
```

旧双机构模式在原有两侧字段后分别追加上述轴1侧和轴6侧校正字段，并记录 `axis2_angle_deg` 与 `axis7_angle_deg`。独立数据记录中的新增校正字段也沿用相同名称；只有勾选的可选字段才写入独立记录 CSV，固定元数据列始终保留。

### `events.csv`

记录阶段变化和动作时间戳，字段为：

```text
event_sequence, plc_time_us, cycle_index, phase, event_name
```

可能出现 `RecordStart`、`ZeroStart`、`ZeroComplete`、`BaselineStart`、`BaselineEnd`、`ForwardStart`、`ReleaseStart`、`ReturnStart`、`ReclampStart`、`FinalForwardStart` 和 `RecordStop` 等事件。

### `zero_calibration.csv`

保存取零窗口内的原始数据，字段为：

```text
sample_index, plc_time_us, fn1_raw, ft1_raw, fn2_raw, ft2_raw, axis2_angle_deg, axis7_angle_deg
```

该文件还保存取零时读取到的轴2、轴7角度，用于后续离线重力补偿分析；当前程序本身不执行重力补偿。

### `experiment.json`

归档时生成的实验元数据，包含模式、记录目录名、本地开始和结束时间、实验状态、实际样本数、持续时间、数据块数量、是否溢出、是否存在样本缺口、ADS 错误标志、零点是否完成、零点样本数、四路零点均值和标准差，以及取零时的 `zero_axis2_angle_deg`、`zero_axis7_angle_deg`。还会记录标定链、机构校正增益和截距、扭矩换算系数、串扰解耦是否写入以及 `gravity_compensation_applied=false`。独立记录模式还包含所选字段掩码 `selected_field_mask`。

## 7. 界面状态与常见问题

- **UI 管道未连接**：WPF 与 C++ 后端之间的本地管道尚未建立。先启动后端，再点击“连接/重连”。
- **ADS 未连接**：后端无法访问 TwinCAT PLC。确认 TwinCAT 处于运行状态、ADS 路由正确且端口 851 可用，再点击“连接ADS”。
- **PLC 自检未完成**：不能准备定位。等待 PLC 自检结束，不要重复点击不存在的自检按钮。
- **准备定位未完成**：不能取零或开始实验。检查轴状态、左限位有效性和 PLC 错误信息。
- **力感零点未完成**：开始按钮会被禁止。先确认机构静止并重新点击“力感取零点”。
- **需要直接记录而自检未完成**：在旧模式面板使用“独立数据记录”区域；记录按钮可以使用，但电缸手动按钮仍会禁用。
- **未勾选记录字段**：独立记录至少需要勾选一个实际数据字段；固定元数据列不计入“至少一个字段”的条件。
- **独立记录正在停止**：停止后程序还会读取最后一个分块并完成写盘，期间不要立即重新开始或切换模式。
- **实时记录缓冲区溢出**：说明上位机未及时读取 PLC 数据块。程序会停止实验；保留已写入数据，并查看 `experiment.json` 中的 `reason` 和 `record_overflow`。
- **样本序号不连续或 ADS 读取失败**：本次数据被标记为不完整。不要把该记录当作完整实验结果使用。
- **保存或写盘失败**：先停止机构并保留记录目录，不要删除已有 CSV；查看界面错误信息和 `experiment.json`，确认磁盘权限和剩余空间。
- **实验结束后没有立即看到最终 JSON**：等待后端完成最后分块读取和写盘收尾，直到记录状态变为“已归档”。

界面曲线只保留最近约 240 个点用于实时显示，不是论文数据的保存来源；论文分析应使用记录目录中的 CSV 文件。

C++ 工程和 WPF 工程位于 `dual_clamp_experiment` 目录。常用编译命令如下：

